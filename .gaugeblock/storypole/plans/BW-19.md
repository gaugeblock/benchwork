# GB-67: Automated Playwright E2E Test Suite in benchwork/web

> **Status:** Blocked (by GB-63, GB-65, GB-66)  
> **Parent Epic:** `GB-64`  
> **Target Scope:** `benchwork` (`benchwork/web`)  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.ts` test and configuration files.  
> 2. Zero flaky timers: tests must use Playwright auto-waiting, locator assertions, and request/response interceptors rather than arbitrary `sleep` timeouts.  
> 3. Headless CI compatibility: runs without GUI displays via `npm run test:e2e`.  

---

## 1. Overview & Objectives

GB-67 introduces an automated browser test framework to prevent regression across Benchwork's core visual features.

GB-67 accomplishes:
1. Configures `@playwright/test` in `benchwork/web` with Chromium driver and standard Vite dev server lifecycle.
2. Implements `e2e/persistence.spec.ts`:
   * Verifies switching panel tabs and reload persistence.
   * Verifies sub-view switching (CAD DAG -> Kanban -> List) and reload persistence.
   * Verifies Benji sidebar width resize and reload persistence.
3. Implements `e2e/benji_chat.spec.ts`:
   * Verifies typing `@task:` brings up the autocomplete suggestions popover.
   * Verifies submitting a message initiates SSE streaming and renders live message deltas.
   * Verifies role selector updates the chat configuration.
4. Implements `e2e/bulk_archive.spec.ts`:
   * Verifies selecting multiple tasks in List and Kanban views triggers the floating action bar.
   * Verifies clicking "Archive Selected" triggers bulk archive API call and updates the UI.
