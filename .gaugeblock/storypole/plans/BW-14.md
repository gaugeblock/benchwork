# GB-62: Resizable, Left/Right Dockable Benji Sidebar with Dynamic Sawhorse Role Selector

> **Status:** Blocked (by GB-63)  
> **Parent Epic:** `GB-60`  
> **Target Scope:** `benchwork` (`benchwork/web`)  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.ts` and `.tsx` files.  
> 2. Docked on left by default, toggleable to right side, persisted in `localStorage`.  
> 3. Smooth drag resizing between 320px and 720px, persisted in `localStorage`.  
> 4. Dynamic role dropdown querying available Sawhorse roles (`Planner`, `Oracle`, `Universal`) from the backend.  

---

## 1. Overview & Objectives

GB-62 builds the unified AI assistant UI shell:
1. Replaces `CopilotRail.tsx` with a modular `assistant/` component tree centered on `BenjiSidebar.tsx`.
2. Implements a fluid drag-to-resize handle with boundary clamping (320px minimum, 720px maximum).
3. Provides docking controls in the sidebar header to toggle between `left` and `right` placement.
4. Adds a dynamic Sawhorse role selector dropdown in the header, defaulting to `Planner` and syncing with backend capabilities.
5. Emits clear status indicators: connection status, current model, and reasoning token indicators.

---

## 2. Component Structure

```text
benchwork/web/src/components/assistant/
├── BenjiSidebar.tsx     # Shell container, drag handle, dock alignment (<240 LOC)
├── BenjiHeader.tsx      # Title, role selector, dock toggle, clear history (<150 LOC)
├── BenjiMessages.tsx    # Message list, auto-scroll, markdown bubbles (<220 LOC)
├── BenjiInput.tsx       # Textarea, send button, autocomplete popover trigger (<190 LOC)
└── useBenjiResize.ts    # Reusable hook for drag resizing and persistence (<100 LOC)
```

---

## 3. Verification Steps

1. Verify clicking the Benji toggle in the CAD navigation header expands/collapses the sidebar.
2. Verify dragging the resize border expands and shrinks the sidebar between 320px and 720px.
3. Verify clicking the dock toggle switches the sidebar between the left and right sides of the main viewport.
4. Verify refreshing the page maintains the sidebar width and dock position.
5. Run `npm run build` in `benchwork/web`.
