# GB-64: Benchwork State Persistence, Bulk Operations & Playwright E2E Quality Gate

> **Status:** Ready  
> **Target Scope:** `benchwork` (`benchwork-core`, `benchwork-cli`, `benchwork/web`)  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.rs`, `.ts`, and `.tsx` files.  
> 2. Zero-loss reload persistence: page refresh never resets active tabs, sub-view modes, or filter state.  
> 3. Atomic bulk mutations: batch task archiving must atomically update stores and broadcast live DAG updates.  
> 4. Full browser E2E test verification via Playwright in `benchwork/web`.  

---

## 1. Executive Summary & Problem Statement

Benchwork currently suffers from three major usability and reliability issues:
1. **Viewport & Sub-View State Loss on Refresh:**
   * Navigating to Kanban or List view and refreshing the browser resets the view back to Panel 2 CAD DAG View.
   * Active filters (e.g. status, repo, kind) and sidebar width are wiped on reload.
2. **Lack of Bulk Archiving:**
   * Archiving only exists as a single-task button inside the task inspection drawer; cleaning up dozens of completed tasks requires dozens of manual drawer interactions.
3. **No Automated End-to-End Browser Testing:**
   * `benchwork/web` lacks test coverage for UI interactions, SSE streaming chat, and state restoration, making regressions easy to introduce.

## 3. Subtasks & Breakdown

* **GB-65 (Feature, P1):** LocalStorage and URL hash persistence for panel navigation, sub-view modes, and sidebar state.

## 4. Execution Plan & Verification Gates

### Step 1: Subtask GB-65 (State Persistence)
* Implement `usePersistentState` hook synchronizing `localStorage` with `window.location.hash`.
* Bind active tab (`#docs`, `#dag`, `#xray`, `#hub`), sub-view (`#dag/dag`, `#dag/kanban`, `#dag/list`), filters, and Benji layout.
* *Verification Gate:* Manual browser reload & unit test

### Step 2: Subtask GB-66 (Bulk Archiving)
* Add `POST /api/v1/dag/bulk-archive` in backend daemon routing to member stores.
* Implement selection state and `BulkActionBar.tsx` in list and kanban views.
* *Verification Gate:* `cargo test -p benchwork-cli --lib daemon::routes_dag::tests`

### Step 3: Subtask GB-67 (Playwright E2E Suite)
* Install `@playwright/test` in `benchwork/web` with headless Chromium.
* Author specs for persistence, Benji streaming, and bulk actions.
* *Verification Gate:* `npm run test:e2e` passing in `benchwork/web`
