# GB-65: LocalStorage and URL Hash Persistence for Panel Navigation and Sub-Views

> **Status:** Ready  
> **Parent Epic:** `GB-64`  
> **Target Scope:** `benchwork` (`benchwork/web`)  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.ts` and `.tsx` files.  
> 2. Client-isolated storage: zero backend database writes for ephemeral user viewport state.  
> 3. Seamless deep-linking: URL hashes (`#dag/kanban`, `#docs`, `#hub`) override or sync bidirectionally with `localStorage`.  

---

## 1. Overview & Objectives

Refreshing Benchwork currently causes disorientation because `App.tsx` and `DagBoardPanel.tsx` reset to default initial state (`activeTab = 'dag'`, `viewMode = 'dag'`).

GB-65 accomplishes:
1. Implements a robust `usePersistentState<T>` custom hook that syncs memory, `localStorage`, and optionally `window.location.hash`.
2. Persists active panel tab (`docs`, `dag`, `xray`, `hub`).
3. Persists sub-view mode inside `DagBoardPanel` (`dag`, `kanban`, `list`).
4. Persists filter selections (`statusFilter`, `kindFilter`, `includeArchived`, `repoFilter`).
5. Persists Benji assistant layout state (`isOpen`, `width`, `dockSide`, `selectedRole`).
