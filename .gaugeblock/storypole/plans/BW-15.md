# GB-63: Wire Real Sawhorse SSE Streaming Inference and Fix Context Injection

> **Status:** Ready  
> **Parent Epic:** `GB-60`  
> **Target Scope:** `benchwork` (`benchwork-core`, `benchwork-cli`, `benchwork/web`)  
> **Key Invariants:**  
> 1. Hard 250 LOC rule on all `.rs`, `.ts`, and `.tsx` files.  
> 2. Zero mock inference: `/api/v1/chat/stream` must invoke real `sawhorse::RoleRouter` streaming.  
> 3. Zero unhandled errors: SSE stream errors must send typed JSON error events, not abort connections abruptly.  
> 4. Multi-repo aware context injection: `@task:KEY` must resolve across both root and member stores.  

---

## 1. Overview & Objectives

In `benchwork-cli/src/daemon/routes_chat.rs`, the `/api/v1/chat/stream` route currently returns hardcoded mock deltas (`"Context initialized for ... on panel ..."`).
Furthermore, while `context_injector.rs` constructs `<gaugeblock_environment>` tags and inspects autocomplete triggers, the injected context is lost because the backend never executes Sawhorse inference.

GB-63 accomplishes:
1. Replaces the mock SSE stream in `benchwork-cli/src/daemon/routes_chat.rs` with real calls to `RoleRouter::stream_role` from `sawhorse`.
2. Connects role parameter (`Planner`, `Oracle`, `Universal`) from the HTTP request to the corresponding configured Sawhorse role.
3. Wires `ContextInjector` to inspect user prompt references (`@task:KEY`, `@doc:ARCHETYPE`, `@symbol:AST`) and expand them into rich context blocks before dispatching to Sawhorse.
4. Updates `useBenjiChat.ts` in the web frontend to consume standard Server-Sent Events (`text/event-stream`) and render live streaming deltas.
