## 1. Executive Summary & Vision

Enable comprehensive management of LLM providers and semantic role bindings directly within Benchwork Panel 4:
1. **Single-Model / Universal Fallback Mode:** A top-level `[default_model]` configuration block where users can specify a single provider, model name, base URL, and API key environment variable. Any role (`Planner`, `System1Router`, `HoleFiller`, `Oracle`) not explicitly overridden inherits `default_model`.
2. **Multi-Mode Support:**
   - In-House / Local Candle Mode (Mode 1)
   - Local GGUF / Ollama / Llama.cpp Mode (Mode 2)
   - Remote API Mode (Mode 3: OpenAI, DeepSeek, Claude, Gemini) with automatic prompt-compiled grammar injection handling.
3. **Interactive Industrial CAD Panel 4:**
   - Universal Config Modal with live inference ping/latency checks.
   - Per-role override accordion.
   - Spool trace table for outbox inspection.

---

## 2. Architecture & REST Endpoints

### Endpoints (`benchwork-cli/src/daemon/routes_config.rs` or `routes_synth.rs`):
- `GET /api/v1/hub/config`: Reads `sawhorse.toml` (or defaults) returning model slots and universal fallback state.
- `POST /api/v1/hub/config`: Validates and safely writes changes to `sawhorse.toml`, reloading runtime handles.
- `POST /api/v1/hub/test-inference`: Lightweight ping verifying API key validity, connectivity, and latency.

## 3. Web UI Components (`web/src/panels/ModelTelemetryHub/`)

- `ModelHubPanel.tsx` (< 200 LOC): Tab switcher between "Model Configuration & Universal API" and "Telemetry Spool Outbox".

- `SpoolTraceTable.tsx` (< 210 LOC): DPO trace inspector, diff viewer, and outbox export actions.
