# `benchwork` — Roadmap & Strategic Horizons

> **Current Lifecycle:** `0.1.0-beta.4` | **Suite:** `gaugeblock`

This document outlines the active milestones, near-term goals, and future horizons for `benchwork`.

---

## 1. Active Milestone: `v0.1.0-beta.4` (Current)

- [x] **4-Panel Industrial CAD Workbench:** Spec Studio, Live Backlog & DAG, Synthesis X-Ray, and Model/Spool Hub.
- [x] **Zero-Subprocess Core Aggregator:** Direct Rust library linkage across `storypole-core`, `sawhorse-core`, and `miter-engine`.
- [x] **Real-Time Dual-Channel Engine:** WebSocket broadcast hub and SSE token streaming daemon in `benchwork-cli`.
- [x] **Dotfile Migration Engine:** `benchwork migrate` discovering and relocating legacy config files into `.gaugeblock/`.
- [x] **Benji AI Engineer Sidecar:** Conversational assistant with staged tool proposals, unified diffs, and audit logging.
- [x] **Model Context Protocol (MCP) Server:** `benchwork-mcp` exposing stdio JSON-RPC 2.0 tools.
- [x] **Strict Line Limit Compliance:** 100% of `.rs`, `.ts`, and `.tsx` source files strictly adhere to the $\le 250$ LOC rule.

---

## 2. Near-Term Horizon: `v0.2.0-beta.1`

- [ ] **Multi-Repo Workspace Switcher:** Dropdown in the CAD header to instantly switch active repositories within a meta-harness.
- [ ] **Interactive AST Tree Visualizer:** Interactive collapsible visual AST graph rendered via WebGL in the Synthesis X-Ray panel.
- [ ] **Live Telemetry Replay:** Scrubbing timeline player to replay past agent synthesis runs and watch repairs step-by-step.
- [ ] **Visual Grammar Rule Builder:** Drag-and-drop Batten CFG rule composer with live syntax highlighting.

---

## 3. Long-Term Horizon: `v0.3.0+`

- [ ] **Headless Agent Swarm Dashboard:** Multi-agent orchestrator panel visualizing concurrent agents executing tasks across distributed branches.
- [ ] **Collaborative WebRTC Pairing:** Peer-to-peer real-time session sharing enabling remote developers and AI agents to pair program inside the same visual workbench.
- [ ] **Custom CAD Extension Plugin API:** Sandboxed WebAssembly extension host for custom domain-specific visualization panels.
