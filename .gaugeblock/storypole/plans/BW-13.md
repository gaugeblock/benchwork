## 1. Overview & Objectives

Currently, Panel 1 is labeled "Panel 1: Spec Planner & /grill-me Chat" and embeds `EngineerChat.tsx` alongside `DocumentViewer.tsx`.
This creates massive redundancy with the sidebar chat rail and breaks brand conventions.

GB-61 accomplishes:
1. Replaces `GrillStudioPanel.tsx` with `DocsSpecsPanel.tsx`.
2. Updates primary navigation tabs in `App.tsx` from "Panel 1: Spec Planner" to "Panel 1: Docs & Specs".
3. Removes `EngineerChat.tsx` and unused chat state from Panel 1.
4. Expands the document viewer to occupy the full panel viewport with a clean sidebar file tree / tab strip for all 9 Chalkline architectural documents.
