# GB-96: Embed static web assets within benchwork-cli crate directory for crates.io packaging

## Context & Root Cause
In `benchwork-cli` (`crates/benchwork-cli/src/daemon/assets.rs:15`), `rust-embed` was configured with:
`#[folder = "../../web/dist"]`
When running `cargo publish` or `cargo package`, Cargo isolates the packaged crate into `target/package/benchwork-cli-<version>/` and verifies compilation. Because Cargo excludes files outside the package root from the crate tarball, `../../web/dist` evaluated to `target/web/dist` (which does not exist), failing publication with:
`error: #[derive(RustEmbed)] folder '.../target/package/benchwork-cli-0.1.0-beta.5/../../web/dist' does not exist.`

## Implementation Steps
1. Create `crates/benchwork-cli/dist` directory and populate it with web assets from `web/dist`.
2. Update `benchwork/web/package.json` build script to ensure `dist/` is synchronized to `../crates/benchwork-cli/dist/` when `npm run build` runs.
3. Update `benchwork/crates/benchwork-cli/src/daemon/assets.rs`:
   - Change `#[folder = "../../web/dist"]` to `#[folder = "dist"]`.
4. Update `benchwork/crates/benchwork-cli/Cargo.toml` if necessary to explicitly include `dist/**`.
5. Verify:
   - Run `cargo fmt --check -p benchwork-cli`
   - Run `cargo clippy -p benchwork-cli --all-targets -- -D warnings`
   - Run `cargo test -p benchwork-cli`
   - Run `cargo publish --dry-run -p benchwork-cli` to certify that packaging and isolated compilation succeed.
6. Commit atomically and merge to `main`.
